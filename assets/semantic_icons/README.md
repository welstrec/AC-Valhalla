# Ilustraciones semánticas originales

Geometría vectorial dibujada para Valhalla Companion. Describe familias de objetos y temas por su nombre; no reproduce arte oficial, capturas, rarezas ni apariencia comprobada del juego.

Estos SVG son fuentes editables del arte incrustado en valhalla/icons.py; no se descargan imágenes y no se necesita acceso a Internet. Los colores y motivos son decorativos.
